## 2. What is original

Everything a player sees or hears is generated by code written for this project:

- **3D models.** The dinosaur, critters, buildings, props, coins and obstacles are
  assembled from Three.js primitives in `src/game/DinoMeshBuilder.ts` and
  `src/game/ThreeGameRenderer.ts`. There are no imported `.glb`, `.fbx`, `.obj`
  or texture files in the repository.
- **Art.** Logos, icons, badges and UI ornaments are inline SVG (for example
  `src/components/GameLogo.tsx`). The submitted build contains only the app
  icons and favicons as binary image files, and those are exports of that SVG.
- **Audio.** Every sound effect — whip, coin, hatch, stampede, fanfares — is
  synthesised at runtime with the Web Audio API in `src/game/SoundEngine.ts`.
  There are no `.mp3`, `.wav` or `.ogg` files in the project.
- **Copy.** Both language sets — the English strings and their Burmese
  translations for menus, maps, skins, missions and toasts — live in the source
  (`src/game/i18n.ts`) and were written for this game. No localisation pack or
  purchased copy is used; the Burmese typeface itself is third-party and listed
  in §3.
- **Code.** Game engine, renderer, daily systems, leaderboard, server handler and
  tests were written for this project. No template, starter kit, asset pack or
  purchased art/audio was used.

## 4. AI use

AI tools were used during development and are disclosed here in full:

- **Google AI Studio (Gemini):** early scaffolding and first-draft UI copy.
- **An AI coding assistant:** refactors, gameplay tuning, documentation and

No AI-generated images, music or voice appear in the game — all visuals are
code-drawn and all audio is synthesised, so there is no generated media asset to
license. All code was read, tested and modified by the developer, who is
responsible for it and can explain any part of it.
